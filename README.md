# PushT imitation learning benchmark: ACT vs Diffusion Policy

Training an ACT policy on LeRobot's PushT dataset and benchmarking it against the pretrained Diffusion Policy on 50 identical simulator seeds.

**Stack:** LeRobot 0.6.1 · PyTorch · Weights & Biases · gym-pusht · Google Colab (T4)  
**W&B project:** [lerobot-pusht-benchmark](https://wandb.ai/rochans-org/lerobot-pusht-benchmark)  
**Notebook:** [`pusht_act_vs_diffusion.ipynb`](pusht_act_vs_diffusion.ipynb) (open in Colab)

## Goal

Measure how a policy I trained myself (ACT) compares to a strong public baseline (Diffusion Policy) on the same task, using a controlled evaluation protocol rather than a single headline number.

## Setup

| | |
|---|---|
| Task | PushT (2D push the T-block onto a target), `gym-pusht`, 96x96 image + agent position |
| Data | `lerobot/pusht`, 206 human demonstrations |
| Trained policy | ACT (ResNet-18 backbone, chunk size 100, CVAE), trained from scratch for 25k steps, batch size 8 |
| Baseline | `lerobot/diffusion_pusht` (pretrained by the LeRobot team, not retrained) |
| Evaluation | 50 episodes per policy, seeds 100000-100049, identical initial states for every policy; success = T covers >= 95% of the target; max 300 steps |
| Hardware | Google Colab, NVIDIA T4 (~45 min training) |

## Reproduce

1. Open the notebook in Colab, select a GPU runtime, add `WANDB_API_KEY` to Colab Secrets.
2. Run all cells. Checkpoints and results are copied to Google Drive.
3. `python scripts/compare_results.py --run "ACT=outputs/eval/act" --run "Diffusion=outputs/eval/diffusion" --start-seed 100000`
